# Package index

## Estimators

First-class stratification and inequality quantities.

- [`social_gradient()`](https://kevisc.github.io/lsastrat/reference/social_gradient.md)
  : Socio-economic achievement gradient
- [`segregation_index()`](https://kevisc.github.io/lsastrat/reference/segregation_index.md)
  : School segregation indices for large-scale assessment data
- [`ieop()`](https://kevisc.github.io/lsastrat/reference/ieop.md) :
  Inequality of educational opportunity (Ferreira-Gignoux)

## Variance engine

The shared plausible-value pooling and replicate-weight machinery.

- [`pool_pv()`](https://kevisc.github.io/lsastrat/reference/pool_pv.md)
  : Pool point estimates and variances across plausible values (Rubin's
  rules)
- [`rep_factor()`](https://kevisc.github.io/lsastrat/reference/rep_factor.md)
  : Replicate-weight variance factors
