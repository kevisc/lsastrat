## What it is

**lsastrat** is an R package (author: Kevin Schoenholzer, ORCID
0000-0001-9892-5869; IICP, USI Lugano) that computes **educational
stratification and inequality quantities from large-scale assessment
(LSA) data** — PISA, TIMSS, PIRLS — as first-class outputs, with
statistically correct **plausible-value pooling** (Rubin’s rules, *t*
reference) and **replicate-weight variance** (BRR/Fay, JK2, JK1).

The gap it fills: general LSA packages (`intsvy`, `EdSurvey`,
`BIFIEsurvey`, `Rrepest`) pool PVs/weights but only for generic
estimators (means, regressions); the stratification quantities, their
pooling, and finite-sample bias correction must be hand-assembled.
`lsastrat` packages them.

## What it does (18 exported functions)

**Estimators** — each returns an `lsastrat_estimate` object: -
[`social_gradient()`](https://kevinschoenholzer.com/lsastrat/reference/social_gradient.md)
— SES (ESCS) → achievement gradient: slope, strength (R²×100),
curvature. -
[`segregation_index()`](https://kevinschoenholzer.com/lsastrat/reference/segregation_index.md)
— D, Gorard’s S, isolation, Hutchens, Theil’s H, mutual information M;
social or PV-pooled academic grouping; replicate **or** two-stage
clustered-bootstrap variance with finite-sample bias correction. -
[`ieop()`](https://kevinschoenholzer.com/lsastrat/reference/ieop.md) —
Ferreira–Gignoux inequality of educational opportunity (variance share
explained by circumstances; raw + df-adjusted). -
[`variance_decomposition()`](https://kevinschoenholzer.com/lsastrat/reference/variance_decomposition.md)
— between/within-school variance and ICC.

**Decompositions:**
[`ieop_decompose()`](https://kevinschoenholzer.com/lsastrat/reference/ieop_decompose.md)
(Shapley attribution of IOp to each circumstance),
[`oaxaca_gap()`](https://kevinschoenholzer.com/lsastrat/reference/oaxaca_gap.md)
(twofold/threefold achievement-gap decomposition).

**Comparison & robustness:**
[`lsa_by()`](https://kevinschoenholzer.com/lsastrat/reference/lsa_by.md)
(run any estimator across countries/subgroups),
[`equity_scatter()`](https://kevinschoenholzer.com/lsastrat/reference/equity_scatter.md)
(OECD quality-vs-equity plot),
[`lsa_multiverse()`](https://kevinschoenholzer.com/lsastrat/reference/lsa_multiverse.md) +
[`lsa_design()`](https://kevinschoenholzer.com/lsastrat/reference/lsa_design.md)
(PV/weight-aware specification curve).

**General engine:**
[`lsa_model()`](https://kevinschoenholzer.com/lsastrat/reference/lsa_model.md)
(fit *any* `lm`/`glm`/multilevel model to PV outcomes with
replicate-weight inference).

**Shared variance engine (exported for reuse):**
[`pool_pv()`](https://kevinschoenholzer.com/lsastrat/reference/pool_pv.md)
(Rubin pooling),
[`rep_factor()`](https://kevinschoenholzer.com/lsastrat/reference/rep_factor.md)
(BRR/JK multipliers). **tidyverse:**
[`tidy()`](https://kevinschoenholzer.com/lsastrat/reference/tidy.lsastrat_estimate.md),
[`glance()`](https://kevinschoenholzer.com/lsastrat/reference/tidy.lsastrat_estimate.md).

## How to verify (from the `lsastrat/` directory)

``` r

# 1. install + run the test suite (expect ~187 passing, 0 failures)
devtools::install(); devtools::test()

# 2. full package check (expect 0 errors / 0 warnings; 1 "new submission" NOTE)
devtools::check()        # or: R CMD check --as-cran lsastrat_0.3.0.tar.gz

# 3. quick smoke test
library(lsastrat); data(pisa_mini)
des <- lsa_design(weight = "W_FSTUWT", repweights = paste0("W_FSTURWT", 1:64))
social_gradient(pisa_mini, paste0("PV", 1:10, "MATH"), "ESCS", design = des)
```

**Real-data validation** (strongest trust check) — requires the OECD
PISA 2022 student file `CY08MSP_STU_QQQ.SAV` placed where the script
expects:

``` sh
Rscript data-raw/validate_pisa2022.R
```

It reproduces, for 6 countries, exact agreement (\<0.01) of gradient
slope/SE/strength with
[`intsvy::pisa.reg.pv`](https://rdrr.io/pkg/intsvy/man/pisa.reg.pv.html)
and of Theil’s H with the `segregation` package, and recovers the known
between-school-variance contrast (Finland ≈0.12 vs Germany ≈0.47).

## How to trust it (what’s already established)

- **Cross-validated** against established tools on identical data:
  `social_gradient` =
  [`intsvy::pisa.reg.pv`](https://rdrr.io/pkg/intsvy/man/pisa.reg.pv.html);
  segregation D & H = `segregation` package; `ieop` =
  weighted-regression R². (Tests + the PISA-2022 script.)
- **Methodologically reviewed**: a multi-lens audit caught and fixed a
  crash, switched normal→Rubin-*t* inference, added the segregation bias
  correction, and the df-adjusted IOp; an adversarial QA pass found no
  surviving defects.
- **Key design choices**: one shared variance engine (`pool_pv`);
  inference uses a *t* reference with Rubin df; segregation bias is
  removed by a two-stage clustered bootstrap nested inside the PV
  pooling (a replicate- weight loop structurally cannot do this);
  optional parallelism via `options(lsastrat.cores = n)` gives identical
  results.
